# Send Matching Files to One Device Right Now

Result page: [innorix.com/en/builder/send-matching-one-now](https://innorix.com/en/builder/send-matching-one-now)

Transfer only the files that satisfy the configured selection criteria from one source device to a single destination device as soon as the workflow runs. Files outside the criteria are left where they are.

| | This example |
| --- | --- |
| Devices | one source device → one target device |
| Starts | right now — the script waits for the run and prints the result |
| Files | only files that match the Type / Size filter (`FILTER_*`) |
| After transfer | none |

Pick one language. Each folder is self-contained: the script, `.env.builder.example` (+ `.env`) and a README.

| Language | Folder |
| --- | --- |
| Node.js | [`nodejs/combo_builder.js`](nodejs/) |
| Python | [`python/combo_builder.py`](python/) |
| Java | [`java/ComboBuilder.java`](java/) |
| C# | [`csharp/ComboBuilder.cs`](csharp/) |
